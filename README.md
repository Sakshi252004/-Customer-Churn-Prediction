# Customer Churn Prediction

## Project Overview

A machine learning project that predicts whether a customer is likely to churn.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Excel
- Power BI

## Project Files

- Model.ipynb - Data cleaning, analysis and machine learning model
- app.py - Streamlit web application
- customer_churn.xlsx - Customer churn dataset

## Features

- Upload customer churn Excel data
- View customer data
- Customer churn analysis
- Select a customer
- Enter new customer details
- Predict churn
- Churn probability
- Low / Medium / High risk classification
- Retention recommendation

## Machine Learning

Random Forest Classifier is used for customer churn prediction.
